# チワワでワン撃 🐕 (Phase 1)

記憶・ブラフ・連番構築のカードゲーム（2〜4人）のデジタル版。ホットシート＋CPU対戦のローカル版。

**遊ぶ**: https://mokemoke0821.github.io/chihuahua-wangeki/

## 遊び方

各プレイヤーは手札4枚・移動トークン2個からスタート。手番で1つ選ぶ:

1. **プレイ** — おしりカード（1〜12）を1枚、**裏向き**で場の右端に置く
2. **公開** — 場のカード列を表にして得点計算
3. **移動** — 場の裏向きカード1枚を、裏向きのまま任意位置へ移す（🪙 トークン1消費）

場が12枚になったら、12枚目を置いた人が**即時強制公開**。

## 得点（公開）

- 左端から `1, 2, 3, …` と連番が続く長さ **n** を数える → 基礎点 = **n(n+1)/2**
- 連番範囲内での**重複**は「数字 × 連続枚数」を減点
  - 例: `1,2,2,3,4` → 10 − (2×2) = **6点**
  - 例: `1,2,3,4,5,5,7,8,8` → 15 − (5×2) = **5点**
- **ワン撃**: 特殊カード不使用で `1〜12` を揃える → **即勝利**
- **ワン！宣言**: 公開前に「連番が〇まで続く」と予想 → 当たり **+5** / 外れ **−5**
- 累計 **150点** 以上で最高得点者の勝利

## 特殊カード（公開者のみ・1公開1枚）

| カード | 効果 |
|--------|------|
| 甘えん坊 | 欠けている数字1つを補完（満額・減点なし） |
| やんちゃ | 欠けている数字1つを無視して接続（その数字ぶん減点） |
| お昼寝 | 今回の重複ペナルティを全て無効化（ワン！の−5は対象外） |

※ 特殊カードで n=12 に到達しても**ワン撃不成立**（66点として計算）

## 構成（開発者向け）

| ファイル | 役割 |
|----------|------|
| `core.js` | ゲームロジック純関数群（**UI非依存**・Phase 2 Django移植の核）。`newGame/legalActions/applyAction/scoreRow` |
| `ai.js`   | CPU AI（記憶モデル＋ヒューリスティック・core非依存で分離） |
| `index.html` | React(CDN)+Babel の UI。`core.js`/`ai.js` を script 読込 |
| `test/core.test.js` | 単体テスト（依存なし・`node test/core.test.js`） |

**設計原則**: UI・CPU AI は core の API のみ経由で状態遷移（直接 state 改変禁止）。state は不変更新。`newGame(seed, playerCount)` で決定論再現可能。
